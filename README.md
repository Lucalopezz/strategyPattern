# Padrão Strategy

Projeto em Java para a apresentação do padrão de projeto Strategy, usando o cálculo de frete como exemplo.

Os códigos ficam em `src/main/java/br/edu/ifsp/frete/`:

- `semstrategy`: cálculo de frete com `if` e `else`, sem usar o padrão.
- `extracao`: primeiro passo para separar os cálculos de frete.
- `strategy`: exemplo com Strategy, incluindo a interface e os tipos de frete.
- `exercicio`: exercício para aplicar Strategy aos descontos de um pedido.
- `exercicio_resolucao`: espaço para resolver o exercício.
- `comparator`: exemplo de ordenação usando `Comparator`.

Cada exemplo tem uma classe com método `main` que pode ser executada pela IDE. O arquivo `pom.xml` contém a configuração do projeto Maven.
